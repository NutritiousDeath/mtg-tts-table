MTG COMMANDER TABLE (TTS) - TEST GUIDE
Version being tested: 1.51
After loading, chat should say:  MTG > Scripts loaded: version 1.49 (...)

HOW TO USE THIS
- One person can test alone: type  !solo on  in chat. You can then act for every seat.
- Load a deck, start the game, put the cards you're testing into your hand (or drag them to the battlefield).
- Go down the list ONE LINE AT A TIME. Each line is:   DO this  ->  EXPECT that.
- Mark each line:  OK   or   WRONG (and write what actually happened).
- "BY HAND" lists at the end of each deck are things the table does NOT automate. The test there is only that the table doesn't do something wrong; you play them yourself.
- If something looks stuck, try these chat commands:  !triggers flush   !import reset   !resync   !order off
- When you report a bug, copy the chat lines from just before and after it. That's the most useful thing you can send.

PART 1 - EVERY GAME (any deck, do these once)
=====================================================================

JOINING AND SEATS
[ ] 1.  DO: sit in a seat.  EXPECT: you can use your own panels; you can't use another seat's.
[ ] 2.  DO: close TTS and rejoin.  EXPECT: chat says your seat is kept, and you are put back in your color automatically.
[ ] 3.  DO: as a spectator (Grey) type  !seat Red  (use a free color).  EXPECT: you move to Red. If the color is taken it says so.
[ ] 4.  DO: type  !resync.  EXPECT: chat tells you what color you are and that your panels were refreshed.

IMPORTING A DECK
[ ] 5.  DO: paste a decklist (or  !import <Archidekt/Moxfield link>) and import.  EXPECT: chat shows timed lines like [3.2s] ... and a finished message, deck appears in your library and your commander in the command zone.
[ ] 6.  DO: have a SECOND person import a deck at the same time as you.  EXPECT: one of you is told an import is already running (with how long ago it last made progress).
[ ] 7.  DO: type  !import reset.  EXPECT: chat says the importer was reset.
[ ] 8.  If any import fails: copy every chat line that starts with [ and send them to the developer.

STARTING THE GAME
[ ] 9.  DO: pick first player, press Start.  EXPECT: everyone draws 7, mulligan panels appear.
[ ] 10. DO: in the mulligan panel click the FRIENDLY / UNFRIENDLY line.  EXPECT: it switches for everyone; it locks once anyone has mulliganed.
[ ] 11. DO: mulligan once, then keep.  EXPECT: the right number of cards go to the bottom.

TURNS
[ ] 12. DO: pass through untap, upkeep, draw, main, combat, end.  EXPECT: untap step untaps your stuff; you draw one card on the draw step; turn passes to the next seat.
[ ] 13. DO: put a creature onto the battlefield this turn.  EXPECT: it shows a Zzz badge (summoning sick) until your next turn.

COUNTERS, TAP, MENUS
[ ] 14. DO: right-click a creature > add +1/+1 counter.  EXPECT: the card shows +1/+1 and its total power/toughness.
[ ] 15. DO: right-click > Clear counters.  EXPECT: counters gone.
[ ] 16. DO: right-click > Goad.  EXPECT: GOADED badge on the card.
[ ] 17. DO: tap a land yourself.  EXPECT: nothing breaks; the MANA tile shows +1 of the land's color (a land that makes one of several colors asks which).
[ ] 18. DO: right-click > Delete card.  EXPECT: the card disappears.

COMBAT
[ ] 19. DO: go to combat, click ATTACK? on a creature.  EXPECT: it shows ATTACKING with a target; click again to change the target.
[ ] 20. DO: finish attackers.  EXPECT: other seats get BLOCK? buttons on their creatures.
[ ] 21. DO: deal damage.  EXPECT: life totals change; a creature with lethal damage goes to the graveyard.
[ ] 22. DO: send a token to the graveyard.  EXPECT: it disappears (tokens aren't real cards).
[ ] 23. DO: a commander dies.  EXPECT: you are asked about the command zone.

LIBRARY SEARCH
[ ] 24. DO: right-click your library > Search. Type  creature  and press SEARCH.  EXPECT: all your creature cards show up.
[ ] 25. DO: type  instant,  then  elf creature,  then  scry.  EXPECT: matching cards each time. If it says "Nothing matches ... (N of M cards had readable type/rules text)", send that exact line.
[ ] 26. DO: click a card.  EXPECT: it goes where the TO: button says (hand or battlefield). Close with CLOSE + SHUFFLE: library shuffles.

TRIGGER QUEUE
[ ] 27. DO: make two triggers happen at once.  EXPECT: you're asked what order to put them on the stack. If nobody answers for 25 seconds they go on in the shown order.
[ ] 28. DO: type  !order off.  EXPECT: you're never asked, they go on automatically. Type  !order on  to turn asking back on.
[ ] 29. If a trigger didn't go on the stack:  type  !triggers flush  and note what chat says.

SPEED / LAG
[ ] 30. DO: type  !perf.  EXPECT: one line with cards, tokens, buttons, and a scan time in ms.
DO: type  !perf watch,  play normally for 15 seconds.  EXPECT: one line listing how many times things were called. Send it to the developer if the table lags.
[ ] 32. Tip: lag while streaming is usually graphics settings / the stream encoder / other programs, not the script. Lower TTS graphics quality first.

PART 2 - EXTRA FEATURES (any deck that has the cards)

SOULBOND (Deadeye Navigator, Wolfir Silverheart, etc.)
[ ] 33. DO: play a soulbond creature with another creature of yours out.  EXPECT: popup "pair?" - click PAIR on the other creature (or SKIP).
[ ] 34. DO: play a different creature while a soulbond creature is unpaired.  EXPECT: YES / NO popup to pair them.
[ ] 35. EXPECT: both paired creatures show  PAIRED: <partner name>.
[ ] 36. Wolfir Silverheart paired: both creatures get +4/+4 shown on the card.
[ ] 37. Deadeye Navigator paired: BOTH creatures get a right-click Activate "{1}{U}: Exile this creature, then return it to the battlefield". Using it blinks the creature (ETB triggers again).
[ ] 38. DO: one of the pair leaves the battlefield.  EXPECT: chat says the pair ended; the bonus goes away.
[ ] 39. DO: right-click a soulbond creature > Soulbond: pair with... / unpair.  EXPECT: fixes a mistake by hand.

METALCRAFT (Etched Champion, Mox Opal style text)
[ ] 40. DO: control three artifacts, then check an Etched Champion.  EXPECT: +2/+2 automatically. Lose an artifact: the bonus goes away.
[ ] 41. A trigger that says "if you control three or more artifacts": EXPECT it decides by itself (no YES/NO).

MANA POOL (the MANA tile left of your command zones - no more chips)
[ ] 52. DO: tap a basic land by hand.  EXPECT: a small dark badge with the number appears at the upper right of that color's circle on the MANA tile (nothing shows at 0).
[ ] 53. DO: tap a dual land / Command Tower.  EXPECT: a popup asks which color; the pool gets that color.
[ ] 54. DO: tap a pain land (Adarkar Wastes) or Talisman.  EXPECT: asks COLORLESS (free) or COLORED (you lose 1 life), then which color.
[ ] 55. DO: tap Ancient Tomb / a Treasure / a mana creature (Llanowar Elves).  EXPECT: the right mana is added (Tomb: 2 colorless and you lose 2 life; Treasure: asks which color).
[ ] 56. DO: tap Gaea's Cradle or a creature with another tap ability.  EXPECT: nothing is added (the table can't tell what you used it for): click the tile yourself.
[ ] 57. DO: cast a spell from hand with mana in the pool.  EXPECT: chat says "pays <spell> from the mana pool (...)" and the numbers drop. Not enough in the pool: it takes what's there and says how many are short.
[ ] 58. DO: activate an ability with a mana cost ({1}{U}).  EXPECT: paid from the pool the same way; if the pool is short you're told to pay the rest.
[ ] 59. DO: click a color on the tile (+1), right-click (-1).  EXPECT: the number changes. Dark Ritual / Lotus Cobra / Spirit Guides add to the pool too.
[ ] 60. DO: move to the next step.  EXPECT: chat says mana pools emptied, the tile numbers vanish.
[ ] 61. Commander tax and cost reducers aren't known to the table: it takes the printed cost. Fix any leftover with right-click on the tile.

TOKEN PILES (OFF by default - turn on with  !stack on  only when you want to test)
[ ] 42. DO: type !stack on, make 5 Saprolings / Squirrels / Insects.  EXPECT: ONE card with an "x5" badge. "Whenever a creature enters" triggers still fire 5 times.
[ ] 43. EXPECT: Treasure / Clue / Food and tokens with abilities are NEVER put in a pile.
[ ] 44. DO: pick a pile up.  EXPECT: you take ONE token; the rest stay as a pile with the badge one lower.
[ ] 45. DO: tap a pile by hand.  EXPECT: only one token taps. The untap step untaps the whole pile.
[ ] 46. DO: right-click one token > add a +1/+1 counter.  EXPECT: that token leaves the pile alone.
[ ] 47. DO: a mass effect (counter on each creature, proliferate).  EXPECT: the whole pile gets it and keeps its xN.
[ ] 48. DO: click ATTACK? / BLOCK? / a target button / attach Equipment on a pile.  EXPECT: one token comes off, the rest stay.
[ ] 49. DO: "for each creature you control" or metalcraft with a pile out.  EXPECT: each token in the pile is counted.
[ ] 50. DO: drag the whole pile to the graveyard (or right-click > Pile: all die).  EXPECT: every token dies, one death each (Blood Artist drains N times).
[ ] 51. Right-click a pile: split off 1 / split off 5 / unstack all / all die.  Commands: !stack off (everything single), !stack unstack, !stack merge.
