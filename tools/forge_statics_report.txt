How the table uses them: statics.lua pairs each Forge S: line with its rules-text line and uses it
only where its own reader didn't understand that line, so what worked stays exactly as it was:
  Continuous   P/T in Statics.compute, keywords in Statics.grants (e.g. "... get +1/+1 and have flying")
  CantBlock / CantBlockBy   combat.lua refuses the block, like flying ("can't be blocked except by
               creatures with flying", "can block only creatures with flying", color / type / power limits)
  CantAttack   combat.lua warns, like defender
  ReduceCost / RaiseCost   chat line when a spell is cast (net generic change and sources; payment unchanged)
Not used on purpose: Enchanted / Equipped statics (equip.lua does those), anything with a condition
(IsPresent, CheckSVar, Condition...), X amounts, other zones (AffectedZone / EffectZone).
